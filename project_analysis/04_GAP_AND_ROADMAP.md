## 남은 데이터 작업

### P0: 시즌 백필 운영

- 2021년부터 현재까지 시범·정규·포스트시즌 전체 실행
- 시즌별 발견 경기 수를 KBO 공식 경기 수와 대조
- 취소·서스펜디드·더블헤더·우천 재편성 사례 검증
- 격리 경기 재처리 리포트와 운영 알림 추가
- 과거 날짜 1군 명단이 실제 요청 날짜를 반영하는지 표본 검증

### P1: 타자×일자 분석 마트

- 타석·박스스코어·등록 상태를 일자 단위로 결합
- 무경기일을 명시적으로 생성
- 3/7/14일, 5/10/20타석 롤링 특징
- 리그·시즌·선수 개인 기준 표준화
- 상대 투수, 구장, 홈/원정, 휴식일 특징
- 결측 원인과 출처 플래그 유지

### P2: 상태 벡터와 변화 탐지

- 상관·VIF를 이용한 중복 특징 제거
- PCA 또는 해석 가능한 선형 축 구성
- `x_t`, `Δx_t`, `Δ²x_t` 생성
- PELT/Bayesian change point로 전환 후보 탐지
- 선수별 기준 상태와 리그 공통 상태 비교

### P3: 비신경망 사이클 모델

- Kalman filter로 잠재 컨디션 추정
- 3~5상태 Gaussian HMM 비교
- 상태 지속시간을 반영한 hidden semi-Markov model 검토
- 다음 상태, 상태 전환 확률, 예상 지속일 예측
- 단순 이동평균·로지스틱 회귀를 기준 모델로 유지

### P4: 검증

- walk-forward 방식의 시간 순서 교차검증
- 선수별·시즌별 일반화 성능 비교
- RMSE, MAE, log loss, Brier score
- 상태 라벨 안정성과 전환 시점 오차
- 부상·2군 이동·휴식일 전후의 설명 가능성 점검

## 알려진 제한

- `--with-player-daily`는 선수×시즌×역할별 추가 요청이 많아 느리다.
- `--with-rosters`는 기간의 모든 달력 날짜에 요청하므로 과거 페이지 날짜
  반영 여부를 운영 전에 검증해야 한다.
- 날씨 테이블은 준비되어 있지만 현재 자동 날씨 소스는 연결되지 않았다.
- STATIZ는 외부 검산용이며 핵심 사실의 유일한 출처로 사용하지 않는다.
- `plate_height`는 PTS 계수의 물리 외삽값이며 실제 측정 높이가 아니다.
