# KBO Statistics Analysis 문서

최종 갱신: 2026-07-19

이 디렉터리는 KBO 타자의 컨디션 사이클을 상태 벡터와 벡터 변화량으로
모델링하기 위한 프로젝트 분석 문서다. 현재 구현된 크롤러와 아직
구현되지 않은 분석 모델을 명확하게 구분한다.

## 현재 상태

- 2021년부터 원하는 종료일까지 날짜 단위 백필이 가능하다.
- 기간 래퍼는 휴식일을 포함한 모든 날짜를 확인하고 모든 종료 경기를 수집한다.
- Naver 문자 중계·PTS, KBO 공식 박스스코어·선수 일별·1군 등록,
  STATIZ 검산 어댑터가 구현되어 있다.
- JSON/HTML 원본과 정규화 SQLite 데이터를 함께 보존한다.
- 실제 2026-05-06의 5경기에서 374타석, 1,405투구, 2,525이벤트를
  수집했고 5경기 모두 `validated` 상태다.
- 컨디션 상태공간 모형, HMM, 변화점 탐지와 다음 사이클 예측은 아직
  구현 대상이다.

## 문서 관리 원칙

- 코드, 테스트 또는 실제 출력으로 확인한 기능만 “구현됨”으로 표시한다.
- 연구 아이디어와 운영 중인 기능을 섞지 않는다.
- API 필드의 의미를 추측하지 않고 원본 응답을 함께 남긴다.
- 데이터 키, 단위, 시간 순서와 출처를 변경하면 데이터 사전도 갱신한다.
