## 해석할 때 주의할 점

- 7개 일정은 KBO 화면에 리뷰 경기 번호가 없었다. `missing_game_list.csv`에 남겼으며, 이를 수집 실패나 0경기라고 단정하지 않는다.
- `player_game_boxscore.csv`의 타격 수치는 Naver 경기 중계 선수 명단에서 읽었다. 위 사례처럼 KBO 공식 일별 기록으로 직접 대조할 수 있지만, 모든 선수·경기를 공식 일별 화면과 대조한 것은 아니다. 따라서 해당 표의 `quality_flag`는 `CHECK`다.
- 1군 등록 현황 원본에는 선수 ID가 직접 표시되지 않아 `roster_daily.csv`의 `player_id`는 빈 칸이며, `CHECK` 상태다.
- 타석 결과 문장이 없는 40개 타석은 `pa_result`가 빈 칸이고 관련 투구는 `CHECK`다. 타석 순서와 `pa_id`는 모두 연결되어 있다.
- `pa_boxscore_count_check.csv`에서 115개 선수×경기는 박스스코어 PA와 재구성 타석 수가 다르다. 무투구 타석·중계 사건의 성격·중계 누락을 원본에서 확인하기 전까지 `CHECK`로 보류한다.

모든 파일의 이름, 위치, CSV 열 이름과 순서는 [DATA_FORMAT_40_110.md](DATA_FORMAT_40_110.md)를 따른다.
